# Feedback and contributions

Feedback is welcome from students, coaches, athletic trainers and sports scientists.

## The fastest way to help

Open an issue: https://github.com/maurocastillomd/baseball-study-hub-open/issues/new/choose

- **Something is wrong in a lesson or figure.** Say where it is, what should change, and give a source if you can.
- **Idea or request.** A topic, tool or improvement.
- **The site is broken.** A page that will not load or looks wrong.

You need a free GitHub account to comment.

## What to know before you suggest text

- Do not paste text, tables or figures from textbooks, paid courses or team documents. Describe the point and cite the source.
- Lessons were drafted with AI tools from cited sources and are still being checked by a practitioner. Corrections with a source are the most useful feedback there is.
- This is educational material. It is not medical advice.

## Pull requests

This repository is generated from a private working copy, so direct edits here get overwritten by the next update.
Small pull requests are still welcome as a way to show a proposed change; accepted changes are applied at the source
and appear in the next update. By contributing you agree your contribution is licensed under the same terms as the
file you change (MIT for code, CC BY 4.0 for lessons and graphics).
